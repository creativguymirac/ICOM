# 3 Étapes pour Être Opérationnel

## 1️⃣ Installer les Dépendances (2 minutes)

```bash
cd backend
npm install
```

Vous verrez:
```
added XYZ packages in 60s
```

---

## 2️⃣ Configurer Gmail (5 minutes)

### A. Générer un App Password
1. Aller: https://myaccount.google.com/apppasswords
2. Sélectionner: **Mail** + **votre système**
3. Copier le mot de passe à 16 caractères
4. (Note: 2FA doit être activé)

### B. Créer le fichier .env
```bash
cp .env.example .env
```

### C. Éditer .env
```env
EMAIL_USER=votre-email@gmail.com
EMAIL_PASSWORD=votre-app-password-16-chars
PORT=3001
NODE_ENV=development
FRONTEND_URL=http://localhost:3000
```

---

## 3️⃣ Démarrer et Tester (2 minutes)

### Terminal 1: Démarrer le serveur
```bash
npm run dev
```

Vous verrez:
```
✓ Serveur démarré sur le port 3001
✓ Serveur email est prêt
```

### Terminal 2: Tester l'API
```bash
curl -X POST http://localhost:3001/api/contact \
  -H "Content-Type: application/json" \
  -d '{
    "nom": "Dupont",
    "prenom": "Jean",
    "email": "jean@example.com",
    "message": "Ceci est un message de test pour vérifier le système est opérationnel!"
  }'
```

Vous verrez:
```json
{
  "success": true,
  "message": "Votre message a été envoyé avec succès..."
}
```

### Gmail: Vérifier l'email reçu
- Inbox: icom.create@gmail.com
- Subject: "Nouveau contact - Jean Dupont"
- Body: Formatage HTML propre

✅ **SUCCÈS! Le système fonctionne!**
